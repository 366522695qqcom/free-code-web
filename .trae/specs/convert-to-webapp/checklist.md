# Checklist

## 项目脚手架
- [ ] Next.js 项目可正常启动（`npm run dev`）
- [ ] Tailwind CSS 样式生效

- [ ] 运行时特性开关系统可用（环境变量控制功能开关）

- [ ] 支持至少 2 个模型提供商（Anthropic + OpenAI）
